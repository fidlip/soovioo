# Security

Soovioo processes personal data of pupils, parents and school staff, so we take security
issues seriously.

## Reporting a vulnerability

**Do not report vulnerabilities through public GitHub issues.** Use one of these instead:

- GitHub private reporting: the _Security_ tab → _Report a vulnerability_,
- e-mail to <info@soovioo.cz> with "Security" in the subject.

Describe where the issue is, how to reproduce it and what impact it may have. You will get
a reply within 5 business days, and we will agree on how and when to fix and disclose it.
Please do not disclose the issue anywhere until the fix is deployed.

## Supported versions

Only the current version on the `main` branch receives fixes. It is also the version running
in the hosted service at `soovioo.cloud`.

## Scope

Reports may cover the code in this repository and the hosted service `*.soovioo.cloud`. Do
not test on other people's data and do not attempt denial-of-service attacks. Test on your
own local instance or on a demo school.
